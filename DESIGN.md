# Social Composer workspace

## Direction

The user selected a matte black workspace with templates, a central canvas, and an inspector. This confirmed direction governs Sprint 4. The concept seed ran with degraded catalog access; its assignment does not replace the user's pinned layout or palette. Build directly from the existing working editor and its real template artwork. No standing image-generation workflow preference is recorded.

## Surface and task

Operate mode. This is a daily creation tool: choose a template, author its content, inspect the artwork, adjust layers, then save or export. Creation stays on the left; selection properties stay on the right. The center reserves its space for the artwork.

## Materials and typography

Use opaque near-black and neutral charcoal surfaces, thin gray boundaries, ivory primary actions, and clear neutral text. The interface has no atmospheric gradients, glass, noise, or glow. Color belongs to the template artwork. Use the local DM Sans for controls and Manrope for headings. Keep compact, readable controls with 44 px targets and visible focus rings.

## Structure

- A compact application bar shows document identity, history, save state, saved designs, and export.
- Templates and assets share a left library with independent tabs. The selected brand filters its template cards; the brand selector uses the supplied mini icons beside its names. AURA defaults to 9:16 for a new canvas while existing artwork keeps its size.
- Canvas size, grid, snapping, and preview zoom stay with the canvas.
- Text and layers share a contextual right inspector. Selecting artwork reveals its controls without resetting template drafts.
- Saved designs open in a modeless drawer with separate restore and remove controls.
- At phone widths, an always-reachable Edit / Preview switch shows either the authoring tools or the canvas. Save and PNG export remain available.

## State and accessibility

Keep all validated storage, recovery, history, and document-operation behavior. Group tablists independently. Form editing must keep focus while values change. Hide inactive mobile regions from keyboard navigation through display visibility. Escape closes the saved drawer and returns focus. Template cards show actual local renderer previews and open settings without creating a post or fetching readings.

## Verification

Run browser suites serially. Inspect desktop and phone layouts in one batched pass and make one focused correction pass. Preserve existing functional coverage while adapting selectors to the new structure. Real template previews are layout samples, not forecasts.
